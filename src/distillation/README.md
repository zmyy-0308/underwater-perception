# SubPipeMini 蒸馏实验

固定 24 种配置，每组五折种子 42 共 120 次。监督基线、标准像素 KL、像素 KL＋1/4 通道蒸馏、双路二分类 Tailoring 适配各增加种子 43 和 44，共 40 次。总计 160 次。

教师使用历史 U3-W128，完整 ResNet-18 U-Net，在 /8 跳连使用相加的通道与空间注意力。无注意力对照使用历史 U1-W128。学生使用灰度差配对实验 H11-W64，保留 LL、LH、HH 的 Haar 投影及 DW 解码器。灰度差对照使用 C6-W64。原始模型源码保存在 original。

每折从该折的历史学生检查点微调 60 轮。教师为对应折的冻结教师。各学生种子控制微调的数据顺序、数据增强、随机深度和训练侧投影。新增蒸馏投影只在训练中使用，部署权重保留原学生架构。

输入为原始 288×512 RGB，保持原预处理及随机水平翻转、亮度偏移与缩放。物理 batch 为 2，通过四步累积达到有效 batch 8。统一使用 Adam、CE＋前景 Dice、AMP、学习率 1e-4 到 1e-6、余弦退火和 weight decay 1e-4。评估固定使用第 60 轮，batch 1，空背景图纳入累计混淆矩阵。

像素蒸馏使用按像素累计的温度 KL，温度为 2、4、6，权重默认 0.5。温度 4 另设 0.25、1.0。特征投影 MSE 和通道空间分布 KL 的权重固定为 0.1，通道分布温度为 2。对齐特征取教师与学生解码器 /4 和 /8 的输出，学生投影到教师通道数。多尺度损失等权平均。

边界带用真值前景内边缘，膨胀半径设为 2 或 5，带内像素权重为 4，其他为 1。前景背景均衡按当前训练 batch 的比例计算，并将比例限制在 0.02～0.98。教师正确性加权为正确像素 1、错误像素 0.1。

Knowledge Tailoring 三组为明确的管道二分类适配实现。特征端取当前训练 minibatch 的教师特征相关矩阵前 16 个 PCA 方向，固定特征向量符号，学生投影后做空间分布 KL。logits 端在半径 2 的真值边界带将教师软目标与真值混合，真值比例随训练从 0.35 线性减至 0.20。这些设置不调用测试标签，也不重训教师。该实现按上述定义报告其结果。

先将 20 份历史教师和学生权重复测到 audit.json，通过后对全部 24 组做真实图像全分辨率损失试跑。正式调度前比较四路与八路的总吞吐。训练均保存优化器、调度器、AMP 和随机状态。

训练结束后串行测两个部署学生架构，FP32、FP16，batch 1，100 次预热、200 次计时、3 次重复。报告模型和包含缩放、掩码后处理的端到端时间。所有逐轮和逐图结果保留，按折、种子进行配对统计。

数据目录 data 指向原服务器的 subpipe-raw-contrast。启动命令为 bash run.sh。状态文件为 status.json，正式完成标记为 TRAINING_COMPLETE，最终打包为 distillation-results.tar.gz。
